# Coin Flow

口座（資金・クレジットカード・貯金）ごとにお金の出入りを記録する家計簿の PWA です。

- 総残高（資金の合計 − 資金で払うカードの未払い額）
- 支出・収入・振替の記録、貸与・借入の管理
- 予約（支出・収入・給与）と、日付が来たときの登録
- クレジットカードの支払い回の管理、キャンセルと返金
- 月ごとの分析（カテゴリ別・日別）
- データは端末の中（IndexedDB）だけに保存。JSON でバックアップと復元
- 日本語・English、ライト・ダーク

公開ページ: https://81goattamer.github.io/coinflow/

## 開発

ビルドは不要です。

```sh
npm start   # http://127.0.0.1:8080
npm test    # 計算のテスト
```

公開するたびに `version.js` の `APP_VERSION` を上げてください。
